
# Komarova bone remodelling model: bifurcation analysis

MATLAB code for the Biomathematics 374 report.

bifurcation_edited.mlx plots the three bifurcation surfaces (A: det(J) = 0,
B: Δ = 0, C: τ = 0) in (g11, g22, g12*g21) space for β1 = 0.2 and β2 = 0.02 day⁻¹
(Figure 1 in the report).

To run: open bifurcation_plot.m in MATLAB and press Run.
Tested in MATLAB R2025a.
